# 暴走ナイン（bousou-nine）

**日本語** | [English](README.en.md)

ファミコンの野球ゲームの操作感を踏襲した、ブラウザで動く野球ゲーム。
Three.js + TypeScript 製で、**2ボタン＋十字キー**だけで投げて打って守って走る。

そのうえに、原作には無い**ローグライト**（1ラン5試合の勝ち抜き・85種のスキル）と、
**銃**と**乱闘**が乗っている。判定は真面目、見た目と名前が狂っている。

> [!NOTE]
> 原作（ファミコンの「プロ野球ファミリースタジアム」シリーズ）は**仕様の参照元**であって、
> 素材は一切含まない。球団名・選手名・能力値はすべて独自に用意したもの。
> 参照した説明書のスキャンは配布元のURLを `CLAUDE.md` に記録してあり、ROMは
> リポジトリに含めない。

---

## 動かす

```bash
npm install
npm run dev      # http://localhost:5173
```

Node.js 20 以上が要る（Vite 7）。ビルドは `npm run build`、テストは `npm test`。

## 操作

| | 1P | 2P |
|---|---|---|
| 移動・選択 | `W` `A` `S` `D` | `↑` `←` `↓` `→` |
| A（打撃 / 投球 / 送球 / 帰塁） | `K` | テンキー `2` |
| B（走塁 / タッチ / けん制切替） | `J` | テンキー `1` |
| Start（采配メニュー） | `Enter` | テンキー `Enter` |
| Select（決定） | `Shift` | テンキー `0` |
| 拡張（銃 / ドロップキック / 一時効果） | `G` | テンキー `3` |

**A と B は場面で意味が変わる**（原作の多目的ボタン方式）。塁の指定は十字キーの絶対方向で、
**上＝二塁 / 左＝三塁 / 右＝一塁 / 下＝本塁**。

<details>
<summary>覚えておくと違うこと</summary>

- **打撃**：`K` を押しっぱなしでフルスイング、振り抜く前に離すとバント。バント中は
  左右で転がす方向、`W` で押しバント。打撃動作の外では左右が**打席内の立ち位置**になる。
- **投球**：ワインドアップ中の上下で緩急、リリースの瞬間の左右でコース、リリース後の
  左右でカーブ／シュート。
- **リード**：けん制されている間、**次の塁の方向を押している間だけ**塁を離れる。
  押さなければ刺されない。深く出るほど盗塁のスタートが良くなる（次の球へ持ち越す）。
- **守備**：捕球はボタン不要（野手をボールに重ねるだけ）。`K`＋方向で送球、
  `J`＋方向でランダンプレイ。

</details>

## 中身

- **2画面構造**：投打の「でっかいモード」と、守備・走塁の「ちっちゃいモード」を自動で切り替える。
- **16球団 × 17人**の選手名鑑と**6球場**。能力値は打率・本塁打・走力・打席左右／
  投球腕・防御率・球速・変化量・スタミナで、**表示される数字はすべて能力値からの導出**。
- **ローグライト**：1ラン＝5試合。回の頭に3枚から1枚引いて選手に付ける（1人3枠まで）。
  **85種**（★1が25 / ★2が33 / ★3が10 / デュオ17）。特定の2つを**同じ選手に**揃えると
  合体スキルが候補に出る。引き直しはラン全体で3回。
- **CPUも対等**：スキルも銃も一時効果も持ち、継投・代打・代走・敬遠・盗塁・タッチアップまで
  判断する。**規則はすべて決定的**なので「読めば対処できる」。
- **1P PLAY / 2P PLAY**（2Pは1枚のキーボードに2枚のパッドを載せる形）。

## 設計の柱

**判定に乱数を使わない。** 打撃・投球・守備・走塁・乱闘はすべて `src/core/` の純粋関数で、
同じ入力からは必ず同じ結果が出る。乱数を引くのは**スキルの抽選**と**その試合の好調選手**
だけで、状態はシードに載っているので**シードを固定すれば試合まるごと再現できる**。

**数値は勘で動かさない。** HRの出やすさもスキルの強さも、`tools/balance/` の計測ツールで
測ってから決める。ツールは判定式を持たず `src/core` の純粋関数をそのまま呼ぶので、
定数を変えれば計測結果も一緒に動く。測った結果は「どちらが大きいか」の**帯**として
`tests/balance.test.ts` に固定してある。

```bash
npm run balance        # 全体のレポート
npm run balance:hr     # ホームランの出やすさ
npm run balance:steal  # 盗塁の窓
# ほか balance:map / :bunt / :control / :relief / :pinchrun など
```

**表示と判定を同じ1か所から出す。** 打者カードの打率も、CPUが継投で見ている球の質も、
描画されるフェンスと当たり判定も、それぞれ出どころは1つ。「画面ではこう見えるのに
実際は違う」が構造的に起きないようにしてある。

## 構成

```
src/core/      判定ロジック（純粋関数。乱数なし）
src/scenes/    でっかい / ちっちゃい / 乱闘の3シーン
src/entities/  選手・ボール・球場・小道具の供給口
src/ui/        HUD・チーム選択・采配メニュー・スキル抽選
tools/balance/ バランス計測（ゲーム本体には入らない）
tests/         1618件
```
